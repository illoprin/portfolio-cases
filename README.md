## 🛠️ Global Tech Stack & Approach

While each project has its own unique goals, the underlying technical standards across this repository include:

- **Semantic HTML5:** Clean, accessible, and SEO-friendly markup structure.
- **Modern CSS3 & SCSS:** Mobile-first responsive workflows using Flexbox, Grid, and CSS Variables.
- **Vanilla JavaScript:** High-performance interactions and state management without heavy framework overhead.
- **Optimization:** Focused on fast loading speeds, optimized assets, and achieving "green zone" scores in Google PageSpeed Insights.
